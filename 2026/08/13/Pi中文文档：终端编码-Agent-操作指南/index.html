Pi 中文文档：终端编码 Agent 操作指南

本文基于 Pi 官方文档 归纳为操作指南，方便中文读者上手与日常查阅。原文持续更新，细节以官方为准。

Pi 是一个极简的终端编码 Agent 框架（coding harness）：核心保持小而稳，通过 TypeScript 扩展、Skills、Prompt 模板、主题和 Pi Packages 按需扩展。包名 @earendil-works/pi-coding-agent，可执行文件为 pi，配置与会话默认在 ~/.pi/agent/。

说明：社区有基于 Pi 的分支产品（如 Oh My Pi / omp）。本文讲的是官方 Pi（pi.dev），不是 omp。

延伸阅读：官方文档长文翻译 · 从零写 Extension

一、认识 Pi

1.1 Pi 是什么

Pi 把「在终端里驱动大模型改代码」做成一套小核心 + 可插拔资源的工具：

能力 作用
交互式 TUI 多行编辑、消息区、页脚显示目录 / 会话名 / Token / 费用 / 当前模型
内置工具 默认 read / write / edit / bash；可选 grep / find / ls
会话树 JSONL 持久化；可 /tree 回跳、/fork / /clone 派生
扩展体系 Extensions、Skills、Prompt Templates、Themes、Pi Packages
程序化接入 -p 单次打印、--mode json 事件流、--mode rpc、SDK

设计原则（官方明确写出）：故意不做内置 MCP、子代理、权限弹窗、Plan 模式、Todo、后台 bash。这些能力可通过扩展/包自行安装，或用容器、tmux 等外部手段补齐。核心保持小，把工作流差异推到扩展层。

官方入口：Documentation · Quickstart · Using Pi

1.2 约 10 分钟上手

  1. 安装：npm install -g --ignore-scripts @earendil-works/pi-coding-agent
  2. 进入项目：cd /path/to/project && pi
  3. 登录或设 Key：交互里 /login，或 export ANTHROPIC_API_KEY=...
  4. 发第一条：Summarize this repository and tell me how to run its checks.
  5. 写项目约定：在仓库根放 AGENTS.md，告诉 Pi 怎么跑检查、什么不能做
  6. 下次继续：pi -c 续最近会话，或 pi -r 挑选历史会话

2.2 认证

两种主流方式：

订阅 / OAuth（交互内）

内置订阅登录包括：Claude Pro/Max、ChatGPT Plus/Pro（Codex）、GitHub Copilot，以及 xAI、OpenRouter、Radius 等。/logout 清除凭据。Token 存在 ~/.pi/agent/auth.json，多数会自动刷新。

API Key

也可 /login 选 API Key 提供商，写入 auth.json。凭据解析优先级：

  1. CLI --api-key
  2. auth.json
  3. 环境变量
  4. models.json 里的自定义提供商密钥

完整提供商表见 Providers。

2.3 第一次会话与项目指令

Pi 默认在当前工作目录操作，可改文件、跑命令。需要可回滚时请用 git。

用 AGENTS.md 写项目级约定（也可全局 ~/.pi/agent/AGENTS.md）：

加载规则简述：

  • 全局：~/.pi/agent/AGENTS.md
  • 从 cwd 向上：AGENTS.md 或 CLAUDE.md
  • 某目录有 AGENTS.override.md 时，该目录用它替换 AGENTS.md / CLAUDE.md
  • 改完后重启，或 /reload
  • 可用 --no-context-files / -nc 关闭

系统提示词：

  • 替换：.pi/SYSTEM.md 或 ~/.pi/agent/SYSTEM.md
  • 追加：同位置的 APPEND_SYSTEM.md

四、会话、分支与压缩

4.1 存储与入口

会话自动保存在 ~/.pi/agent/sessions/，按工作目录组织；每个会话是一棵树结构的 JSONL。

交互内 /resume 的挑选器支持：打字搜索、Ctrl+P 路径显示、Ctrl+S 排序、Ctrl+N 仅命名会话、Ctrl+R 重命名、Ctrl+D 删除（优先走 trash CLI）。

4.2 /tree、/fork、/clone

/tree /fork /clone
结果 同一会话文件内改活跃叶子 新会话文件 新会话文件
典型用途 在同一文件里试不同路径 从某条用户消息另起炉灶 把当前活跃分支复制一份再继续
摘要 切分支时可选分支摘要 无 无

/tree 选中用户消息：叶子回到其父节点，并把该消息放进编辑器，可改后重发形成新分支。选中助手/工具等：叶子移到该节点，编辑器为空，可从该点继续。

切离某分支时，Pi 可对「被放弃分支」做摘要并挂到新位置，避免丢上下文。可用设置 branchSummary.skipPrompt 跳过询问。

4.3 Compaction（上下文压缩）

上下文逼近窗口上限时自动压缩（也可 /compact [说明]）：

  • 触发大致：contextTokens > contextWindow - reserveTokens
  • 默认 reserveTokens = 16384，keepRecentTokens = 20000
  • 旧消息变成结构化摘要 + 最近消息继续发给模型
  • 摘要会累计跟踪读过/改过的文件列表

7.2 Skills（按需能力包）

符合 Agent Skills 约定：目录 + SKILL.md。启动时只注入名称与描述；真正执行时用 read 加载全文（渐进披露）。也可 /skill:name 强制加载。

常见路径：

  • ~/.pi/agent/skills/、~/.agents/skills/
  • 项目：.pi/skills/、.agents/skills/（需信任）
  • 可在 settings 里挂 Claude Code / Codex 的 skills 目录

SKILL.md 需有 name 与 description（description 决定何时被选用，写具体一点）。

7.3 Prompt Templates

放在 ~/.pi/agent/prompts/*.md 或 .pi/prompts/*.md。文件名即命令：review.md → /review。

参数：$1 $2、$@ / $ARGUMENTS、${1:-default} 等。

八、安全与隔离

8.1 项目信任（不是沙箱）

若项目存在 .pi/settings.json、.pi 下的扩展/Skills/模板/主题、系统提示文件，或项目 .agents/skills，交互启动时会询问是否信任。决定记在 ~/.pi/agent/trust.json。

信任后才会加载项目本地设置、资源、缺包安装与项目扩展。拒绝则跳过这些。**AGENTS.md / CLAUDE.md 仍会加载**（除非关了 context files）。

非交互（-p / json / rpc）不弹窗：默认 defaultProjectTrust: "ask" 时与 "never" 一样忽略受保护资源；可用 --approve / --no-approve 单次覆盖。

8.2 没有内置沙箱

Pi 没有内置沙箱。工具与扩展以启动用户的权限读写文件、跑 shell。这是刻意设计：它要直接对接你本机工具链。真正隔离请用容器 / VM / 微虚拟机，见官方 Containerization（Gondolin、Docker、OpenShell 等）。

实践建议：

  • 不信任的仓库或无人值守任务，放进隔离环境
  • 不要随便挂载宿主机 ~/.pi/agent（含凭据与会话）
  • 只挂所需工作区；需要防写时用只读挂载或拷贝进出
  • 最小权限 API Key / 短时凭据；不需要网络就断网

漏洞报告：走仓库 Security Policy，不要开公开 issue。
