Oh My Pi (omp) 全量快捷键指南

一、快速上手

  • **/hotkeys**：在 omp 会话内运行，列出当前构建生效的全部按键组合。该列表会反映：
    • 用户磁盘上的重映射（~/.omp/agent/keybindings.yml）；
    • 扩展注册的额外绑定。

二、模型与计划模式

快捷键 动作 ID 含义
Ctrl+P app.model.cycleForward 向前循环切换角色模型
Shift+Ctrl+P app.model.cycleBackward 向后循环切换角色模型
Alt+P app.model.selectTemporary 为本次会话临时选择一个模型
Alt+M app.model.select 打开模型选择器并设置各角色模型
Alt+Shift+P app.plan.toggle 切换 Plan 计划模式

三、思考块与工具显示

快捷键 动作 ID 含义
Ctrl+T app.thinking.toggle 切换思考块（thinking block）可见性
Shift+Tab app.thinking.cycle 循环切换思考级别
Ctrl+O app.tools.expand 展开 / 收起工具输出（工具调用卡片）
Ctrl+Shift+O app.tools.toggleVisibility 显示 / 隐藏工具活动
Ctrl+R app.history.search 搜索提示词历史

Ctrl+O 在多个场景通用：展开工具输出、展开压缩（compaction）摘要、以及 Tree 选择器内切换筛选。它是 omp 里最常用的「查看细节」键。

四、编辑器与消息

快捷键 动作 ID 含义
Ctrl+G app.editor.external 在 $VISUAL / $EDITOR 中编辑当前草稿
Ctrl+Q、Ctrl+Enter app.message.followUp 排队发送一条跟进消息（流式输出期间排队）
Alt+Up、Shift+Up app.message.dequeue 把已排队消息取回编辑器重新编辑
Alt+R app.retry 重试上一轮失败的助手回复

补充说明：

  • 流式输出时，**Enter** 把输入投递到 steer 队列（与空闲时普通提交一致），**Ctrl+Enter**（app.message.followUp）则投递到跟进队列——技能（Skill）的调用方式同样遵循这个「提交键位即投递方式」的规则。
  • Windows Terminal 会吞掉 Ctrl+Enter，所以 app.message.followUp 额外绑定了 Ctrl+Q（与 GitHub Copilot CLI 相同，该组合也用于 Agent Dashboard 新建 agent 描述与 hook 编辑器的提交）。

五、剪贴板与终端显示

快捷键 动作 ID 含义
Alt+L app.display.reset 重置终端显示（清屏重绘，滚动历史异常时使用）
Alt+Shift+L app.clipboard.copyLine 复制当前行
Alt+Shift+C app.clipboard.copyPrompt 复制整个提示词
Ctrl+Shift+V、Alt+Shift+V app.clipboard.pasteTextRaw 原样粘贴剪贴板文本（不做折叠/整理）
Ctrl+V（macOS 另加 Cmd+V，Windows 另加 Alt+V） app.clipboard.pasteImage 粘贴剪贴板内容（图片优先，无图片时回退为文本）

平台注意事项：

  • Windows Terminal 可能先于 omp 处理 Ctrl+V（终端粘贴命令），此时图片粘贴请用 Alt+V 兜底；
  • 支持 OSC 5522 增强粘贴的终端可以直接把剪贴板 MIME 数据发给 omp，图片会以 [Image #N] 附件形式粘贴。

六、语音

快捷键 动作 ID 含义
按住 Space（默认无按键绑定） app.stt.toggle 按住说话（push-to-talk）：按住空格录音、松开转写
Ctrl+L app.live.toggle 开始 / 停止实时语音模式（等价于 /live）

STT 默认没有键位绑定——默认行为是按住空格录音。如果你希望「按一下切换开关」，可以在 keybindings.yml 里给 app.stt.toggle 绑一个组合键。

七、Agent Hub

Agent Hub 是子 agent 的实时名册与控制面板（查看状态、读取转录、直接指挥、复活 parked 的 agent）。

快捷键 动作 ID 含义
Alt+A app.agents.hub 打开 / 关闭 Agent Hub
Ctrl+S app.session.observe 打开 / 关闭 Agent Hub（旧版动作）
双击 ← —（非按键动作） 主会话编辑器为空且当前会话有 agent 时，从编辑器打开 Hub

双击 ← 不是可重映射的按键动作。焦点在子 agent 上时，双击 ← 返回主会话，而不是打开 Hub。

八、进程控制：中断、退出与挂起

这些是 TUI 运行时层的全局行为：

按键 含义
Esc 取消 / 退出当前模式（压缩中、handoff 生成中、自动重试中按 Esc 会中断对应流程）
Ctrl+C（单击） 清空编辑器内容
Ctrl+C（500ms 内双击） 关闭并退出 omp（会话收尾：快照草稿 → dispose → 退出）
Ctrl+D（空编辑器时） 退出 omp
Ctrl+Z 挂起 TUI（释放终端模式，发送 SIGTSTP），再按一次恢复（SIGCONT 重绘）
Shift+Ctrl+D 全局调试快捷键（TUI 在组件分发前优先处理）

九、Tree 会话树选择器

Tree（/tree，或在空编辑器双击 Esc 默认触发 doubleEscapeAction = "tree"）用于在会话分支之间浏览、搜索与切换：

按键 含义
Up / Down 移动选择（可循环）
Alt+Up / Alt+Down 跳到上 / 下一条用户或助手回合
PageUp / PageDown，或 Left / Right 翻页
Home / End 跳到第一个 / 最后一个可见项
Enter 选择节点
Shift+Enter 直接总结并切换（跳过总结选择提示）
Esc 有搜索词时先清空搜索；否则关闭选择器
Ctrl+C 关闭选择器
直接输入字符 追加到搜索词
Backspace 删除搜索字符
Shift+L 搜索为空时编辑 / 清除标签（label）
Ctrl+O 向前循环筛选条件
Shift+Ctrl+O 向后循环筛选条件
Alt+D / Alt+T / Alt+U / Alt+L / Alt+A 直接跳到对应筛选（如 labeled-only 只看带标签分支）

十、会话切换器

会话选择 / 最近会话列表（全屏选择器）中的操作：

  • Tab — 切换「当前文件夹 / 全部项目」范围；
  • Esc — 取消；Ctrl+C — 退出；
  • Delete，或搜索为空时的 Backspace — 删除会话（需确认）；
  • 鼠标滚轮 / 左键点击 — 在全屏选择器中移动 / 选中；
  • 搜索支持跨 id / title / cwd / 首条消息 / 前缀文本 / 路径的多 token 匹配。

十一、自定义快捷键

配置文件

用户重映射位于 ~/.omp/agent/keybindings.yml（注意：不是 config.yml，也没有嵌套的 keybindings 对象）。它是 YAML 映射：键是动作 ID，值是一个组合键字符串或字符串数组。

  • 组合键写法与 UI 显示一致，大小写不敏感：Ctrl+P、Alt+Shift+P、Shift+Enter、Ctrl+Backspace；
  • 把动作设为空数组即可禁用：
  • 旧版未加命名空间的动作名会被自动迁移；keybindings.json、keybindings.yaml 也仍然接受并迁移到 keybindings.yml。

命名 Profile 的合并规则

使用命名 profile 时，先加载默认 profile 的 agent/keybindings.*，再由活动 profile 的 keybindings.yml 按动作逐个覆盖（继承文件在启动期间只读）。快捷键描述的是「用户面前的终端/键盘」，不随 profile 切换而变化，因此用户级重映射在任意 profile 下都生效，除非该 profile 显式覆盖。

平台兼容性备忘

  • Windows Terminal：Ctrl+V 可能被终端粘贴命令截获 → 图片粘贴用 Alt+V；Ctrl+Enter 被吞 → 用 Ctrl+Q（若你的 keybindings.yml 已把 Ctrl+Q 分配给其他动作，用户重映射优先，app.message.followUp 就只保留 Ctrl+Enter）。

十二、扩展开发者的保留快捷键

开发扩展 / 技能时，以下组合键是保留的，注册会静默忽略：ctrl+c、ctrl+d、ctrl+z、ctrl+k、ctrl+p、ctrl+l、ctrl+o、ctrl+t、ctrl+g、ctrl+q、alt+m、shift+tab、shift+ctrl+p、alt+enter、escape、enter。

它们被内置动作占用（如 Ctrl+P 模型循环、Ctrl+O 工具展开、Ctrl+T 思考可见性、Ctrl+G 外部编辑器、Ctrl+Q 跟进消息、Alt+M 模型选择器、Shift+Tab 思考级别循环等），扩展不得抢占。

总结

  • 高频必记：**Ctrl+P（切模型）、Ctrl+O（展开工具输出）、Ctrl+T（思考块）、Shift+Tab（思考级别）、Alt+M（模型选择器）、Ctrl+Enter（排队跟进消息）、Alt+A（Agent Hub）、Alt+L（重置显示）、Ctrl+R**（搜索历史）。
  • 记不住没关系：会话内运行 /hotkeys 随时查看当前生效的全部按键。
  • 全部按键都可通过 ~/.omp/agent/keybindings.yml 重映射或禁用，动作 ID 以 keybindings.md 的 Common action IDs 表为准。
